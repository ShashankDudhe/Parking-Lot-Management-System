# Parking Lot Management System

A console-based Parking Lot Management System developed using **Core Java**. This project demonstrates object-oriented programming concepts and basic vehicle and parking slot management.

## Features

- Park a vehicle in an available parking slot.
- Remove a parked vehicle using its registration number.
- Search for a parked vehicle.
- Display the status of all parking slots.
- Display parking statistics, including total, occupied, and available slots.
- Prevent duplicate vehicle entries.
- Validate user input and handle invalid menu choices.
- Support for Cars and Bikes.

## Technologies Used

## How to Run

1. Clone or download this repository.
2. Open the project in IntelliJ IDEA or another Java IDE.
3. Make sure Java JDK is installed.
4. Run `Main.java`.
5. Follow the console menu to manage the parking lot.

## Application Menu

1. Park Vehicle
2. Remove Vehicle
3. Search Vehicle
4. Display Parking Slots
5. Display Parking Statistics
6. Exit
